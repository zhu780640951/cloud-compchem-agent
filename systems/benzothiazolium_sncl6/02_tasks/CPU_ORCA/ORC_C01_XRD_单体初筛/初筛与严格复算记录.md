# 有机阳离子实验几何初筛：进度与验收

本任务是孤立 C7H6NS+ 阳离子在 CIF 实验几何下的参考试算，不包括水、SnCl6 或晶体嵌入，不能直接用于晶体发光归属。电荷 +1，单重态基态，ORCA 6.1.1，PBE0/def2-SVP/RIJCOSX，TDA，单重态10根、三重态10根，12进程。

初筛运行约20.905 s，SCF 13步，采用ORCA默认能量收敛方式；末步部分密度指标偏离所列阈值。于是以 ConvCheckMode 0 保留相同模型进行更严格复算，输出保存在 orc_c01_xrd_strict_20261030，未覆盖初筛。

严格复算运行约23.965 s，SCF 21步；ORCA报告SCF收敛，单重和三重 Davidson 均报告残差收敛，ORCA正常结束。打印出的部分SCF密度指标仍未全部达到各自阈值，ORCA允许其他指标超额满足时判定收敛，因此此处标记为 needs_review，后续应检查收敛策略/轨道稳定性，而不是宣称所有阈值均通过。

严格复算基态实验几何下垂直激发：最低单重激发态 S1 = 4.341 eV；最低三重激发态 T1 = 3.416 eV。它们不是优化激发态的发射能，不能直接对实验发光峰归属。完整的输入、输出、GBW、CIS、密度文件已取回。
