# 两个有机二聚体真空参考初筛（2026-10-31）

从固定实验晶胞优化结构中选择两种反演相关近邻；芳环重原子几何中心距离约3.6523和3.7107 Å。各模型30原子，电荷+2，晶体几何，真空无嵌入，PBE0/def2-SVP/RIJCOSX TDA，12进程，10单重+10三重。

两作业分别103.5秒和86.1秒，均ORCA正常结束，S/T Davidson残差报告收敛；S1约4.287和4.282 eV，T1约3.405和3.378 eV。部分打印SCF密度/DIIS指标未满足各自阈值，需进一步复核。单体参考使用的是原始实验几何，二聚体使用优化几何；不应把二者能量差直接归为堆积作用。带正电真空二聚体不含晶体静电与水、无机环境，结果仅为诊断参照，不能直接赋予晶体发光结论。全部输入、输出、轨道已回传。
