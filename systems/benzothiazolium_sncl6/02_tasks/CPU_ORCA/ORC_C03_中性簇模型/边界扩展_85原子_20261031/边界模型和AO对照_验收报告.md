# CPU 边界模型与波函数对照验收

85原子模型 ORCA 正常结束，SCF 第156周期收敛；466电子，233个双占轨道。最终能量 −6322.306893552817 Eh，末次能量变化 −3.4652e−10 Eh（阈值1e−8），轨道梯度 1.5852e−6（阈值1e−5）。8个云端输入、输出、点电荷、结构、GBW及记录已逐一 SHA-256 校验回传。

新加入两个水分子的 Mulliken 电荷和分别约 −0.050619 e、−0.064515 e；Mulliken 方法依赖基组与布居分区，不能单凭此判定异常极化。最近量子原子与点电荷相距1.577 Å，存在人工极化风险；此结果只是边界敏感性诊断，不能直接把79原子和85原子总能量相减，也不能认定发光机制。

79原子两组GBW用 ORCA 6.1.1 orca_2json 导出轨道系数与重叠矩阵。两组79原子坐标、870个AO标签与重叠矩阵一致（最大差0）；各223个占据轨道的正交误差最大分别3.14e−14、1.08e−10，对应电子数446。占据子空间重叠矩阵的最小奇异值0.4942、均值0.99773；说明大多数方向相似，也存在明显不同的占据子空间方向，并非仅凭能量判断。密度矩阵指标 Tr[(ΔP S)^2]=6.0520，这不是电子转移量。两组 Mulliken 原子电荷最大差约0.02591 e（硫）。粒子数差约−4.1e−13 e。

AO标签、几何和重叠矩阵核对一致；导出文件未提供完整逐壳基组细节，不能将其夸大为独立逐项基组审计。原子布居、电荷和边界效应均需结合更合理的嵌入模型进一步验证。原始结果与哈希保存在云端原始结果目录，波函数对照数据在相邻 JSON；云端保留导出文件及日志。
