# 独立初猜SCF复核结果

79原子QM簇 +2、shell1点电荷−2；PBE0/def2-SVP、RIJCOSX、TRAH、12进程。独立默认初猜不读取前序GBW。

ORCA报告SCF经273 cycles收敛并正常结束，运行54分06.213秒。最终重积分SCF能量 -6169.688098653297 Eh，轨道梯度 8.6062e−7（阈值1e−5）；最终能量变化−4.4838e−10 Eh（阈值1e−8）。积分电子数约446.00166（α与β各223.00083），与形式显式电子446接近，积分误差需结合网格理解。

先前同壳层重启结果的最终重积分SCF能量约 -6169.685881768 Eh；独立初猜结果低约 0.002216885 Eh（约 0.0603 eV）。因此两种初猜的能量没有完全重现，可能进入不同自洽解；必须比较占据轨道、密度和稳定性，不能单靠总能量确定原因或真实基态。两组相同点电荷、几何和方法的比较仍需核对全部实际输入及能量约定。

基态SCF对照并非发射计算。外部点电荷缺少Pauli排斥与极化，边界物理性和电子泄漏仍待审查。轨道稳定性尚未重新完成；能量较低不等于物理态已证实。
