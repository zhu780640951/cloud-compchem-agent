# QE 初始收敛测试

43原子原始CIF结构，QE 7.5、A100、PBE-D3(BJ)；五次自洽均正常结束且GPU加速开启。首次 60/480 Ry、2×2×2 耗时约40秒；80/640 2×2×2约50秒，100/800 2×2×2约61秒，80/640 3×3×2约51秒，80/640 4×4×3约100秒。

正确提取第一段总受力块后：80/640与100/800在2×2×2网格的能量差0.353 meV/atom、最大力分量差0.000525 eV/Å；80/640下3×3×2与4×4×3的能量差0.00248 meV/atom、最大力分量差0.0002075 eV/Å。按本项目预设的1 meV/atom及0.005 eV/Å目标，80/640与3×3×2用于当前初步优化。此验证只覆盖原始结构基态总能和受力；带隙及优化结构参数敏感性尚未复核。

最初程序错误地从QE verbosity=high输出的最后一个D3分力块提取受力，得到零差，这是错误结果；已用总受力块重新解析并更新 convergence_analysis.json。Drive上的 convergence_progress.json 内 forces_ry_bohr 是旧解析，不可用于受力收敛结论；其能量、时间和状态字段有效。完整归档 QE_G01_results.tar.gz 含实际赝势、输入、输出和修正后的分析。
