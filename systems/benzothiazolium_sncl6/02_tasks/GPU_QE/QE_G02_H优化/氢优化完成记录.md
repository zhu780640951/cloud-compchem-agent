# 固定实验晶胞 H 优化

原始实验晶胞，PBE-D3(BJ)，80/640 Ry，3×3×2；16个H自由、27个重原子固定。第一段到 max_seconds=720 正常暂停，QE输出 JOB DONE 不代表几何收敛；保存完整BFGS及波函数重启目录后，第二段使用 restart_mode 续算。最终 QE 报告 bfgs converged，累计32次SCF、31个BFGS步；最大H受力分量 0.0137922 eV/Å，小于0.02 eV/Å；核验43原子、16个H，重原子分数坐标不变。

完整原始输入、两段输出、最终坐标及验证存于 H_relax_results.tar.gz，第一次因输入段顺序错误退出的记录也保留在归档。注意此结构仅用于固定重原子、优化氢的位置，不能代替全原子优化。
