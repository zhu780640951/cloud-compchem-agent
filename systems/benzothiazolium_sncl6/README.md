## 当前科研进展与重要排查教训

1. **GPU / QE 周期性 DFT 主线（可靠）**：
   - PBE-D3 固定实验晶胞全原子优化完成（最大残余力 ≤ 0.02 eV/Å）；
   - 采样 Kohn–Sham 带隙约 **2.65 eV**（间接带隙），VBM 主要由有机阳离子 π 轨道贡献（约 86–90%），CBM 主要来自 `[SnCl₆]²⁻` 的 Sn 5s–Cl 3p 反键态（约 90–96%）；
   - SOC 对带边影响极小（+0.0065 eV）；后续最关键的待补验证为周期性 **HSE06（`QE_G07`）**。
2. **CPU / ORCA 嵌入团簇诊断教训（待修正点电荷模型）**：
   - `ORC_C01` 孤立阳离子参考计算已完成；
   - `ORC_C03`（79/85 原子点电荷嵌入簇）排查出**点电荷重复单元构建不对称产生了虚假宏观偶极与约 1.5–2 V/Å 的人为电场**，导致等价阳离子间静电势相差约 15 V、S₁ 异常抬升至 ~6.9 eV。相关诊断脚本、静电势核查记录与分析日志已完整保留在 `CPU_ORCA/ORC_C03_中性簇模型/` 中，为后续重建基于反演中心对称的中性点电荷环境提供直接依据。
