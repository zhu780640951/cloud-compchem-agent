# CPU / GPU 分工与分阶段计算方案

日期：2026-10-30。版本：v1。性质：计算设计与任务清单；本轮没有启动任何正式晶体作业，也没有启动 Colab 运行时。

## 1. 研究主线与结构依据

目标是把结构、电子态、激发态弛豫和实验光谱连成证据链，回答发光发生在什么片段、堆积和水起什么作用、Sn 是否改变自旋相关跃迁，以及结构在所研究条件下是否稳定。

当前 CIF：`00_原始结构/苯并噻唑SnCl4.cif`，SHA-256 为 `ed23e88c8f84151de88f25c1ddd3b617e21a626e7ba6e403d5853217436c7a12`。

- 完整晶胞：(C7H6NS)2[SnCl6]·2H2O，43 原子，总电荷 0；P−1，Z=1，275 K 实验晶胞。
- 含两个苯并噻唑鎓阳离子、一个独立 [SnCl6]2− 和两个水分子。Sn 位于反演特殊位置，展开后去重，不能生成 44 原子。
- Sn—Cl 平均约 2.4297 Å，基态八面体接近规则。有机片段与 Sn 没有第一配位层直接成键。
- 两种近邻芳环堆积的平面间距约 3.556 和 3.487 Å；水参与 N—H···O 和 O—H···Cl 接触。
- 因此，必须同时比较有机局域激发、堆积相关激发、有机—无机电荷转移和无机局域激发；仅凭结构不能预先确定其中哪一种发光。

结构来源：同目录《晶体分析与计算路线.md》及《晶体结构核算.json》。文件名记录合成原料的习惯沿用，不更名。

## 2. 两个平台的职责

| 平台 | 已验证环境 | 本轮职责 | 资源安排 |
|---|---|---|---|
| Google Cloud CPU | ORCA 6.1.1；12 vCPU / 192 GiB，系统报告约 188.7 GiB；单核和双核 H2 测试通过 | 分子/嵌入团簇、吸收与激发态、发射、SOC、振动和局部相互作用 | 先按一个重作业使用 12 个进程；首个代表算例测内存和耗时，再调整 |
| Colab GPU | QE 7.5 GPU 的 A100 微型测试及 Drive 恢复通过；当前不预留 GPU | 周期晶体优化、电子结构、SOC 带边对照、有限位移受力、必要的周期验证 | 使用实际分配的显卡试算；不把过去的 A100 分配视为下次硬件保证 |

这里按平台与主要软件划分任务。QE 的 DOS/PDOS 等后处理可以使用 Colab 主机 CPU；不能把所有 QE 可执行文件都视为已验证 GPU 加速。HSE、相对论计算及声子相关流程各自先做小规模能力测试。

CPU 的 MaxCore 是每个处理进程的内存参数，且不是所有模块总内存的严格上限。初始建议 `%pal nprocs 12 end`，`%maxcore 8000`，需要时按实测升到 10000 MB/进程；对应名义预算约 96–120 GB，保留系统和额外数组空间。此为首轮试算设置，不是内存需求的结论。最近根文件系统空闲约 68.3 GiB，正式任务先估计 scratch，完成后回传并清理该任务可再生临时文件，不改原始数据。[ORCA 内存说明](https://www.faccts.de/docs/orca/6.1/tutorials/first_steps/memory.html)

## 3. GPU / QE 任务

| 编号 | 优先级 | 计算内容 | 主要问题与交付 |
|---|---|---|---|
| QE_G01 | 第一轮 | 43 原子模型核验、PBE+色散、赝势/截断能/k 网格收敛 | 提供经过验证的统一周期基线；记录每个赝势的版本、价电子数和哈希 |
| QE_G02 | 第一轮 | 固定实验晶胞、固定重原子，优化全部 H | 修正 XRD 中受约束的 H 位置，保留水和质子化状态 |
| QE_G03 | 第一轮 | 在同一实验晶胞内放开全部原子 | 得到周期环境中的基态参考结构，量化 SnCl6、氢键和堆积变化 |
| QE_G04 | 第一轮 | SCF/NSCF、能带、DOS/PDOS、带边电荷密度 | 查明价带顶/导带底来自有机、Sn/Cl 还是混合；建立候选电子转移方向 |
| QE_G05 | 关键复核 | 有/无 SOC 的电子结构配对 | 检查带隙、带边排序、轨道组成和简并变化；不代替 ORCA 的态间 SOC |
| QE_G06 | 关键复核 | 变晶胞优化与固定实验晶胞结果对照 | 识别晶格松弛对水、堆积及带边的影响；区分约 0 K 优化与 275 K 实验晶格 |
| QE_G07 | 关键复核 | 代表结构的 HSE06 单点/带边检查 | 复核 PBE 的带隙和有机/无机带边排序；先验证 GPU 编译与该任务的兼容性 |
| QE_G08 | 分阶段稳定性 | 在充分弛豫结构上做 Γ 点振动筛查 | 找出局部软模；Γ 点无虚频不能视为整个晶体动力学稳定的结论 |
| QE_G09 | 深入计算 | 声子 q 网格或有限位移超胞的收敛 | 在全布里渊区检验动力学稳定性；2×2×2 超胞为 344 原子，先测资源 |
| QE_G10 | 机制触发 | 同自旋、同电荷、同超胞下的激发态局域化/畸变对照 | 当 CPU 显示明显无机或 CT 弛豫时，进一步检验自陷候选，而不是预设 STE |
| QE_G11 | 有明确脱水问题后 | 含水/合理脱水产物与水参考态的反应能或自由能 | 研究水结合或脱水倾向；指定产物及水化学势，不直接比较不同组成总能量 |
| QE_G12 | 有明确温区问题后 | 适当超胞与温度的 AIMD | 观察水取向、氢键重排和局部结构动态；有限时长轨迹不代表长期热稳定性 |

初始方法建议：PBE 加经程序验证的 D3(BJ) 色散；Sn 使用合适的相对论赝势。先依据赝势推荐值选截断能范围，再逐级测试；电荷密度截断能按赝势类型和收敛结果选择，不预设统一倍数。k 点可从 2×2×2、3×3×2、4×4×3 等候选开始，依据实际倒易晶格间距调整。旧记录中的 80/640 Ry 或 3×3×2 不自动视为本轮已收敛。

建议验收起点：能量变化 <1 meV/atom；相应原子受力分量变化 <0.005 eV/Å；最终优化最大残余力 ≤0.02 eV/Å，关键激发模型必要时收紧。带隙需额外检查变化约 ≤0.02 eV 和带边排序稳定。这些是拟采用目标，达到前不得标记收敛。实验晶胞全原子优化是主基线，变晶胞结果作为另一种明确标记的结构，不能混用坐标。

QE SOC 需要匹配的全相对论赝势以及 `noncolin`、`lspinorb` 设置；尽量使用同套相对论赝势配对比较开关，避免把换赝势的差异误归因于 SOC。[QE 相对论说明](https://www.quantum-espresso.org/Doc/pw_user_guide/node10.html)

声子优先考虑有限位移调用同一套包含色散的 QE 受力，从而使二阶力常数与优化势能面一致。如选择 DFPT/ph.x，先核验当前版本、色散项及相对论设置的支持情况。HSE 的使用范围先限定关键电子结构复核；不默认可直接进行同方法 DFPT 声子。[QE PHonon 使用范围](https://www.quantum-espresso.org/Doc/user_guide_PDF/ph_user_guide.pdf)

## 4. CPU / ORCA 的模型体系

| 模型 | 最小组成与电荷 | 作用与边界 |
|---|---|---|
| ORC_M01 | 苯并噻唑鎓单体，15 原子，+1，闭壳层基态 | 建立有机局域激发参照；分别标明晶体几何与孤立弛豫几何 |
| ORC_M02A、M02B | 两种实际堆积的二聚体，各 30 原子，+2 | 比较堆积导致的态混合/能量变化；保留晶体静电环境，不能把真空中的带电二聚体解离当晶体行为 |
| ORC_M03 | [SnCl6]2−，7 原子，−2，嵌入环境 | 无机局域激发参考；检查阴离子束缚、弥散基组和电子密度，不能单靠裸气相二阴离子作归属 |
| ORC_M04 | 化学计量中性环境簇候选：2 阳离子+[SnCl6]2−+2 水，43 原子 | 同时容纳有机、无机和水的激发态与 CT；从周期近邻重建完整分子/配位单元，不机械剪裁晶胞盒子 |
| ORC_M05 | 扩大的 QM 区或不同嵌入壳层 | 检验 CT、能级和几何对模型尺寸、边界及环境的敏感性 |

43 原子中性簇是起点候选，并非仅凭原子数就证明边界合理。应检查关键 π 堆积和氢键是否在量子区域中完整，必要时显式增加相邻分子。外围点电荷要检验中性边界/电势收敛及过度极化；由周期电荷或静电势构建的环境也要报告具体来源。最终候选必须通过 QM 区与环境敏感性验证，不能把任意一圈形式点电荷作为唯一晶体环境。

## 5. CPU / ORCA 任务

| 编号 | 优先级 | 计算内容 | 主要交付 |
|---|---|---|---|
| ORC_C01 | 第一轮，与 QE 并行 | 单体基态、吸收及 S/T 激发态参考 | 有机片段的 S/T 能级、振子强度和轨道性质 |
| ORC_C02 | 第一轮 | 两种二聚体在晶体几何/环境下的激发态 | 堆积诱导的能量移动、态混合和电子/空穴分布 |
| ORC_C03 | 第一轮 | 嵌入 [SnCl6]2− 与中性环境簇的垂直激发 | 比较无机局域态、LE 和有机—无机 CT |
| ORC_C04 | 第一轮必做分析 | 候选态 NTO、跃迁密度、片段电子/空穴定量 | 根据密度给态分类，不能只根据 HOMO/LUMO 或自动标签判断 CT |
| ORC_C05 | 候选进入发射前 | 泛函、基组、QM 区及嵌入的敏感性 | 确认候选态能量顺序与空间分布是否可靠；检查基态稳定性和三重态自旋污染 |
| ORC_C06 | 核心发光计算 | 选定有机、堆积或 CT 候选做 S/T 激发态几何优化及态跟踪 | 得到实际候选发射几何；记录 Sn—Cl、堆积、水/氢键变化与态交换 |
| ORC_C07 | 核心发光计算 | 在相应激发态几何上算发射能和结构重组 | 给出发射能/波长及方法区间，区分垂直吸收、垂直发射和 0–0 能量 |
| ORC_C08 | 核心自旋验证 | 候选 S/T 的 SOC 与 ΔEST | 评估系间窜越和磷光通道的可能性；Sn 贡献用兼容的全电子相对论设置检验 |
| ORC_C09 | 候选确定之后 | 合理势能面上的频率/Hessian、振动分辨谱和辐射/ISC 等速率 | 在方法适用范围内估算辐射寿命、谱形与自旋转换；非辐射过程按需要补足 |
| ORC_C10 | 与机制关联 | 堆积、氢键、结晶水的受控对照与相互作用分析 | 明确环境对几何和激发态的影响；不把简单真空带电片段结合能当晶体结合能 |

方法起点：用适度基组做模型检查和初筛，再在候选上提高到三重ζ及适当弥散函数；对 CT 候选比较预先确定的长程校正方案（例如 CAM-B3LYP）和另一合理杂化方案。第一轮每个模型可先取 10–20 个单重态及三重态，随后依据能窗、态密度和求解收敛扩展；态数不是预定的充分性结论。优先 TDA 筛查，关键态必要时与全 TDDFT/其他适当近似复核。每个模型先验证电子数、电荷和基态多重度。

态跟踪应依据 NTO/跃迁密度和片段性质，不能在整个优化中把固定的 root 序号当作固定物理态。发射对象也不能只由基态结构上的某个波长与实验接近而选择。[ORCA TDDFT、NTO 与态跟踪](https://www.faccts.de/docs/orca/6.1/manual/contents/spectroscopyproperties/tddft.html)

含 Sn 的 SOC 是必须单独核验的方法节点。ORCA 相应 TDDFT-SOC 路线不提供 ECP 的 SOC 积分，不能使用忽略 Sn 核区 SOC 的默认 ECP 设置来证明 Sn 的重原子作用。候选 SOC 模型应采用与哈密顿量匹配的全电子相对论基组；例如先测试 X2C 与 x2c-TZVPall 体系及所需 SOC 路径的兼容性，也可按手册选择匹配的 DKH/ZORA 路线。标量相对论设置本身不等于已经包含 SOC。必要时在同一几何上重算全电子 SCF 与激发态，不能把 ECP 筛选结果直接当全电子 SOC 波函数。[SOC/ECP 限制](https://www.faccts.de/docs/orca/6.1/manual/contents/spectroscopyproperties/tddft.html#soc-and-ecps)、[相对论方法与基组](https://www.faccts.de/docs/orca/6.1/manual/contents/essentialelements/relativistic.html)

ORCA_ESD 可用于适当模型的振动谱和相关速率；开展前需要可靠的极小值、Hessian 及与固定嵌入/约束相适应的振动处理。单发光态近似下，辐射寿命为 1/kr，实验寿命还取决于非辐射和其他态间过程；有 ISC/RISC 时需要对应的动力学模型。ΔEST 小、SOC 大或振子强度非零都不能单独给出实验寿命/PLQY。[ORCA ESD](https://www.faccts.de/docs/orca/6.1/manual/contents/spectroscopyproperties/esd.html)

## 6. 先后顺序和两平台衔接

1. 统一 CIF、原子标签、分子完整性、电荷、目录和任务编号；初始结构标为 R_XRD。
2. 两条线并行：GPU 做 QE_G01→G02→G03；CPU 做 ORC_C01 与二聚体的小模型/环境预检查。CPU 参考任务使用的几何单独记录，不冒充已经从优化晶体导出。
3. 冻结一份通过受力验收的固定晶胞结构 R_fixed，从中导出完整分子及近邻关系。GPU 做 G04/G05；CPU 做中性嵌入模型、C03/C04，识别候选。
4. GPU 做 R_vc 的结构对照及关键 HSE 验证；CPU 对少量候选做 C05→C06→C07/C08。每种几何、方法和嵌入都有唯一模型 ID，跨平台只按可追溯结构衔接。
5. 根据候选和实验现象展开声子、速率、STE、脱水或 AIMD。完整范围保留在清单中，深度和顺序由上一阶段结果决定。
6. 汇总成机制对照表和结构/带边/NTO/发射/SOC 图，保留支持与不支持的证据。

目前没有在本工作目录发现晶体正式 QE/ORCA 产物；已核验的是结构和云端微型测试。桌面另有标为“失败版本”的旧项目目录，历史审核提到过部分计算和未收敛任务。本轮不依据历史摘要把它们计为已完成；如需复用，必须先核对原始输出、CIF/几何、方法、赝势/基组、模型边界和逐态收敛，保留失败记录。

## 7. 完成判据与保存

- QE：不仅检查 JOB DONE，还检查 SCF、几何受力、收敛测试及所需后处理文件齐全；声子检查势能面、超胞/q 网格与数值收敛。
- ORCA：不仅检查正常结束，还检查 SCF、请求态数、逐态求解收敛、优化收敛、态性质及对应模型。未收敛态单独标识，不能从总任务状态中隐藏。
- CPU 保存输入、完整输出、模型/点电荷、轨道检查点、NTO/跃迁密度、几何轨迹和所需 Hessian；一项重任务先测内存/磁盘再扩展。
- GPU：连接→挂载 Drive→恢复 QE/赝势/输入到运行时本地磁盘→计算→在一致的保存点回存日志、完整检查点与任务信息→读回验证→释放。大任务恢复方式要针对相应任务类型先核验；不假定 H2 的成功涵盖所有优化和后处理重启。
- 每项任务记录输入哈希、软件版本、硬件、方法、启动/结束时间、最大资源占用和状态；结果分为 planned/running/completed/failed/needs_review。
- 所有本地输入、日志、恢复脚本及回传结果归档在用户指定工作目录。GPU checkpoint 同时保存在 Drive，避免依赖临时机文件。

## 8. 实验对照与结论边界

发射/激发谱、寿命、PLQY、变温行为、含水/脱水后的结构与光谱是后续机制判别依据；缺少的数据不填推测值。目前不把历史记录中的任意峰位当作已重新核对的实验输入。

- 有机局域荧光：需要对应的电子/空穴分布、弛豫几何、发射能及跃迁强度。
- 堆积相关发光：需要二聚体/扩展模型相对单体的对照及相应激发态结构和密度变化；不能仅凭 π 堆积距离称为激基缔合物。
- 磷光：需要可信的三重态候选、发射几何和 SOC/辐射通道，并与寿命及温度数据对照。
- CT：需要电子/空穴的片段转移及环境/泛函稳健性；基态带边分属有机/无机只是线索。
- TADF：还需要合适的 ISC/RISC 动力学和温度行为，不能只看 ΔEST。
- STE：需要相同物理条件下的局域化、结构弛豫及能量证据，并排查有限团簇边界。
- Sn 增强或猝灭发光：需要相应跃迁与竞争速率的证据，SOC 存在本身不能确定增强或猝灭。
