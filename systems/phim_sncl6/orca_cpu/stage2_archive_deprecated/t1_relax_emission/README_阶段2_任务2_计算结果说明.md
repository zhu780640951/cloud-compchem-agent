## 三、发光本质与论文讨论（Discussion）写作提纲

1. **构型弛豫特征（微观畸变）**：
   从基态 $S_0$ 到最低三重态 $T_1$，有机阳离子的咪唑环与苯环之间的共轭 $\text{C–C}$ 单键缩短，苯环出现典型的醌式（Quinoidal）伸缩，二面角发生微幅平面化调整。这种自陷激子晶格畸变释放了约 $0.90\ \mathrm{eV}$ 的弛豫能，使发射峰从近紫外大幅红移至 **$497\ \mathrm{nm}$（蓝绿光区）**。
2. **NTO 轨道确证发光纯度**：
   在 VESTA 中打开 `NTO_Hole_T1_to_S0.cube` 与 `NTO_Particle_T1_to_S0.cube` 可以清晰看到：
   * 空穴与电子均高度定域在有机阳离子的 $\pi$ 共轭骨架上，二者空间重叠良好；
   * 发射跃迁具有纯正的 $^3(\pi, \pi^*)$ 局域激发（LE）特征，解释了该晶体的高磷光发光效率与长余辉寿命。
