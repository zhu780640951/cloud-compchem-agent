## 5. 阶段 2 出错原因（01d / 01e 诊断）

| 计算 | 设置 | HOMO / LUMO (eV) | 结论 |
|---|---|---|---|
| 01e | DKH + ANO-RCC，无点电荷 | −8.53 / −0.47 | 正常 |
| 01d | DKH + ANO-RCC，有点电荷 | −12.54 / −8.92 | 与阶段 2 完全相同，异常 |
| 01a / 01c / 03 | def2 或 ZORA-def2 基组，有点电荷 | 正常 | 正常 |

结论：异常只在 DKH + ANO-RCC 与裸点电荷同时使用时出现。最可能的机理是 ANO-RCC 中较弥散的基函数让电子"溢出"到附近的正点电荷上（电子溢出问题），把空轨道整体拉低。

## 6. 激发态空穴–电子分析（相当于 Angew 图 S17 / Multiwfn IFCT）

做法：对每个激发态，按 TDA 激发振幅（权重 ≥ 1×10⁻⁴）把占据轨道（空穴）和空轨道（电子）的 Löwdin 片段组成加权求和，得到空穴、电子在 CatA / CatB / [SnCl₆] / H₂O 上的分布。片段间电荷转移按 IFCT 公式 Q(F→G) = h_F·e_G 估算，"局域比例" = Σ h_F·e_F。注意：当空穴和电子分布相同、但分散在两个片段上时（如 S₄、S₅），IFCT 会给出约 15% 的"CatA↔CatB 转移"，这实际上是两个阳离子之间的激子离域，不是真正的电荷转移。

**要点**
1. **基态结构**：S₁–S₃ 是 [SnCl₆] 内部激发（局域 91–95%，几乎不吸光）；亮态 S₄、S₅ 是阳离子 ππ*，在 CatA 与 CatB 之间约 75 : 21 离域（激子耦合）；真正的电荷转移态只有 S₁₃（CatA→[SnCl₆] 67%，5.48 eV）和 S₁₅（CatB→[SnCl₆] 96%，5.79 eV），都很弱。
2. **三重态基本都是局域态**：T₁–T₁₃ 局域比例 ≥ 91%，T₁₄ 为 84%；只有 T₁₅（4.95 eV）在 CatB 与 [SnCl₆] 之间混合（局域 58%）。T₁、T₂ 是阳离子 ³ππ*（98%），T₅、T₆、T₉–T₁₃ 是 [SnCl₆] 三重态。低能区没有电荷转移三重态。
3. **T₁ 结构（TZVP）**：发光态 T₁ 局域在 CatA 上 95%，电荷转移成分约 3%。

**两处更正（以 TZVP 结果为准）**
- 此前根据 04c（SVP）写的"T₁ 在 T₁ 结构上带 13% CatA→[SnCl₆] 电荷转移"，来源是 SVP 基组下 CatA π* 与 [SnCl₆] σ* 能级过近而发生人为混合。TZVP（04c2）中两者相差 0.40 eV，没有混合，T₁ 的电荷转移成分约 3%。
- 此前根据 02a（SVP）提到的"94% 电荷转移性质的三重态（4.35 eV）可作为能量转移桥梁"，在 TZVP（02b）中不存在，对应态是局域态。因此 [SnCl₆] 三重态 → 阳离子 T₁ 的能量转移，目前只能依据三点作定性讨论：能量下坡约 1 eV；两片段间有氢键接触；T₃、T₈、T₁₅ 含 6–24% 的 [SnCl₆] 成分。
