### 三个最重要的结论

1. **吸收起点在紫外约 248 nm(5.0 eV)**,来自阳离子苯基咪唑的 π→π\* 跃迁,强度明显(S3、S4 的振子强度 f 约 0.37)。
2. **SnCl6 到阳离子的电荷转移态在约 5.4 eV 以上,f 接近 0**,对吸收几乎没有贡献。
3. **PBE0 给出的 3.3–3.9 eV(317–379 nm)"低能跃迁"是泛函假象**:换成范围分离泛函后,同类电荷转移态被抬高约 2 eV。引用这个体系的计算结果时,应以 ωB97X-D3 为准。

### 需要提前知道的限制

- 模型是**气相孤立簇**(1 个 SnCl6²⁻ + 2 个阳离子 + 2 个水),没有晶体周期性和晶体场。
- 基组只有 def2-SVP,重原子固定在 X 射线位置,只放松了氢。
- 所以结果适合**判断跃迁的性质和相对位置**,不适合直接和晶体的实验吸收峰位逐点比较。详见第十一节。

## 二、基础概念:先把词讲清楚

量子化学计算的目标只有一个:在给定原子位置下解出电子的波函数和能量,再从波函数推出光谱、轨道等性质。下表把这个项目里出现的所有术语一次讲完,后面的章节会反复用到。

| 术语 | 一句话解释 | 在本项目中的角色 |
| --- | --- | --- |
| 单点能(single point) | 固定原子位置,只算一次电子能量 | 第 2 步,检验模型能不能正常收敛 |
| 几何优化 | 按能量梯度移动原子,找能量最低结构 | 第 3 步,只移动氢原子 |
| 波函数 / 分子轨道(MO) | 电子在分子里的分布,用原子轨道线性组合表示 | 所有结果的基础 |
| HOMO / LUMO | 最高被占轨道 / 最低空轨道 | 判断电子从哪里出发、到哪里去;第 148 / 149 号轨道 |
| Hartree(Eh)、eV | 能量单位:1 Eh = 27.2114 eV = 627.51 kcal/mol | ORCA 输出用 Eh,光谱用 eV 和 nm |
| DFT(密度泛函理论) | 用电子密度而不是多电子波函数来算能量 | 本项目的核心方法 |
| 交换相关泛函 | DFT 里唯一需要近似的部分,不同泛函 = 不同近似 | PBE0、ωB97X-D3 就是两种泛函 |
| 杂化泛函 | 混入一部分精确(Hartree–Fock)交换 | PBE0 混入 25% |
| 范围分离泛函 | 近程用 DFT、远程逐渐切换到精确交换 | ωB97X-D3,专门修正电荷转移态 |
| D3BJ | Grimme 色散校正(范德华吸引) | 在输入里写 D3BJ 即可 |
| 基组(def2-SVP) | 用来展开轨道的一组数学函数 | 最小的"可用"级别,快但精度有限 |
| ECP(赝势) | 用有效势代替重原子内层电子 | Sn 的 28 个内层电子由 def2-ECP 代替 |
| TD-DFT | 含时 DFT,算激发态能量和跃迁强度 | 第 4、6 步 |
| 振子强度 f | 一个跃迁吸光有多强(没有单位) | f > 0.1 才算明显吸收 |
| 电荷转移(CT)态 | 电子从一个片段跳到另一个 | 本项目的关键问题 |
| 局域激发(LE) | 电子跳跃发生在同一片段内 | 阳离子 π→π\* |
| Löwdin / Mulliken 布居 | 把轨道分给各个原子的百分比 | 第 5 步,判定轨道在哪个片段 |
| cube 文件 | 把轨道在空间格点上的值存成文件 | 用来画轨道图 |

### 一个要记住的直觉

一个分子吸收一个光子,就是一个电子从某个**被占轨道**跳到某个**空轨道**。跃迁的能量约等于两个轨道的能量差(再加上电子–空穴相互作用的修正),跃迁强度取决于这两个轨道在空间上重叠得有多大。如果两个轨道分别在不同的片段上(比如一个在 SnCl6 上,一个在阳离子上),重叠小,就是弱的电荷转移跃迁;如果两个轨道都在同一个苯环上,重叠大,就是强的局域 π→π\* 跃迁。这正是本项目结果的骨架。

### 为什么要自己编译 OpenMPI

ORCA 做并行计算时,会调用 `mpirun` 在多个进程之间传数据。ORCA 官方预编译包是按 OpenMPI 4.1.x 编译的,而 Debian 13 默认只提供 5.x,两个大版本的接口不兼容,直接用会报错或崩溃。所以我下载了 OpenMPI 4.1.8 源码,编译后装到独立目录 /opt/openmpi-4.1.8,不影响系统自带版本。

### 环境变量

程序要能找到 ORCA 和 OpenMPI,必须设置路径。我把设置写进了 /etc/profile.d/orca.sh,每次登录自动生效:

```bash
export PATH=/opt/orca:/opt/openmpi-4.1.8/bin:$PATH
export LD_LIBRARY_PATH=/opt/orca:/opt/openmpi-4.1.8/lib:$LD_LIBRARY_PATH
```

- `PATH`:告诉系统去哪些目录找可执行程序。
- `LD_LIBRARY_PATH`:告诉程序去哪些目录找运行时库文件。

### 调用 ORCA 的规则

ORCA 做并行时会在内部再次调用自己,所以**必须用完整路径** `/opt/orca/orca` 启动,而不能只写 `orca`。

```bash
/opt/orca/orca input.inp > output.out
```

- 输入文件里用 `%pal nprocs 6 end` 指定 6 个进程。服务器是 6 个物理核(12 个线程),量子化学计算以物理核为单位,超线程几乎不加速,所以用 6 而不是 12。
- `%maxcore 6000` 表示每个进程最多用 6000 MB 内存,6 个进程共约 36 GB,留出余量给系统。
- 长任务统一放在 tmux 里:`tmux new -s calc` 开会话,`Ctrl+B` 再按 `D` 脱离,`tmux attach -t calc` 重新进入。

### pip 安装 Python 包

Debian 13 保护系统自带的 Python,默认不让 pip 直接装包,所以用了:

```bash
pip3 install --user --break-system-packages numpy scikit-image matplotlib
```

`--user` 把包装到你自己的目录,不动系统文件,风险很小。我原本想建虚拟环境,但缺少 ensurepip 模块建不成,才改用这个方式。

## 六、体系与结构准备:从 CIF 到计算模型

量子化学程序不认 CIF,只认原子的笛卡尔坐标(单位 Å)。所以先要把晶体文件转成一个分子团簇。

### 6.1 这个晶体是什么

| 项目 | 数据 |
| --- | --- |
| 化学式 | C18H22Cl6N4O2Sn |
| 分子量 | 657.78 |
| 空间群 | P-1(三斜,有反演中心),Z = 2 |
| 晶胞参数 | a = 7.6939, b = 10.9454, c = 15.4984 Å |
| 晶胞角度 | α = 86.698°, β = 80.216°, γ = 82.508° |
| 晶胞体积 | 1274.36 Å³ |
| 组成 | 2 × 2-苯基咪唑鸢阳离子 + 1 × SnCl6²⁻ + 2 × H2O |

即 **2-苯基咪唑鎓六氯合锡酸盐二水合物**。阳离子是 C9H9N2⁺(咪唑环上连一个苯环,两个 N 上带 H),阴离子是正八面体的 \[SnCl6\]²⁻,Sn 为 +4 价。

这是一种典型的"杂化金属卤化物"晶体:无机阴离子单元(SnCl6)和有机阳离子通过 N–H···Cl 氢键以及水分子连起来。

### 6.2 从分数坐标到笛卡尔坐标

CIF 里的原子位置是分数坐标 (x, y, z),表示占晶胞边长的比例。转成笛卡尔坐标要乘以晶胞矩阵 M。三斜晶系的公式如下:

```latex
M = \begin{pmatrix}
a & 0 & 0 \\
b\cos\gamma & b\sin\gamma & 0 \\
c\cos\beta & \dfrac{c(\cos\alpha-\cos\beta\cos\gamma)}{\sin\gamma} & \dfrac{c\,v}{\sin\gamma}
\end{pmatrix},\quad
v=\sqrt{1-\cos^2\alpha-\cos^2\beta-\cos^2\gamma+2\cos\alpha\cos\beta\cos\gamma}
```

笛卡尔坐标 = 分数坐标 × M。比如一个原子在 (0.25, 0.5, 0.1),就是沿 a 走 0.25 倍、沿 b 走 0.5 倍、沿 c 走 0.1 倍后到达的点。

### 6.3 构造分子团簇

不同离子在非对称单元里可能落在晶胞不同的角落,直接转坐标会得到被"切开"的分子。所以我做了这几步:

1. **解析 CIF**:读取 atom\_site 表,去掉每个数后面括号里的误差(如 0.2500(3) → 0.2500)。
2. **按键分块**:用共价半径之和×1.25 作为成键判据,把相连的原子归为一组,得到 SnCl6、两个阳离子、两个水。
3. **最小镜像**:对每个片段平移整数倍晶胞向量,使它落在离 SnCl6 最近的位置,保证各分子依然完整。
4. **检查**:打印 Sn–Cl 键长和总原子数,确认没有漏原子、没有原子重叠。

结果得到 **53 个原子**:SnCl6(7) + 2 × H2O(3+3) + 2 × C9H9N2⁺(20+20),直接就是 CIF 的一个完整非对称单元。不需要再用对称操作扩展。

### 6.4 模型的电荷与电子数

- 总电荷 = 2×(+1) + (−2) + 0 = 0,中性簇。
- 自旋多重度 = 1(闭壳层单重态)。
- 总电子数 326,其中 Sn 用了 def2-ECP 赛势替代 28 个内层电子,所以明确参与计算的价电子数为 298。
- 输入里写 `* xyz 0 1`:电荷 0,自旋多重度 1。

### 6.5 氢原子为什么要单独处理

X 射线衍射是看电子云的,氢只有一个电子,位置最不准。CIF 里的 N–H 为 0.68–0.73 Å、O–H 偏短,这是 X 射线的系统性假象(不是我转换坐标的错误),真实的 N–H 约 1.01 Å,O–H 约 0.97 Å。

如果直接用这些短键氢算能量,会得到很高的假能量(我们确实实测过,见第九节的能量对比:相差约 0.35 Eh,即 222 kcal/mol)。所以做了两件事:

1. 先把 N–H 重置为 1.01 Å、O–H 重置为 0.97 Å(沿原键方向拉长)。
2. 再用 DFT **只优化氢原子**,重原子(Sn、Cl、C、N、O)全部冻结在 X 射线位置。

这样保留了实验测到的骨架和氢键网络,只修正不可靠的氢位置。

## 八、计算原理详解

这一节用尽量少的公式把用到的方法讲清楚。你只需要理解“它在算什么、为什么这么选、哪里不准”。

### 8.1 密度泛函理论(DFT)

分子里所有电子的完整波函数很难求。DFT 的思路是:不求波函数,只求**电子密度** ρ(r),因为基态能量是电子密度的泛函(Hohenberg–Kohn 定理)。实际用 Kohn–Sham 方法:假设一组互不相互作用的虚拟电子产生和真实系统一样的密度,它们满足

```latex
\left[-\tfrac{1}{2}\nabla^2 + v_{\mathrm{ext}}(\mathbf r) + v_{\mathrm{H}}[\rho](\mathbf r) + v_{\mathrm{xc}}[\rho](\mathbf r)\right]\varphi_i(\mathbf r)=\varepsilon_i\,\varphi_i(\mathbf r)
```

四项依次是动能、核吸引势、电子库仑排斥势、交换相关势。唯一不知道精确形式的是交换相关项,不同的近似就是不同的“泛函”。解出的 φᵢ 就是**分子轨道**,εᵢ 是**轨道能**。由于势依赖于密度,要反复迭代直到自洽,这就是 SCF。

### 8.2 泛函的选择:PBE0 与 ωB97X-D3

| 泛函 | 类型 | 精确交换比例 | 特点 |
| --- | --- | --- | --- |
| PBE0 | 全局杂化 | 固定 25% | 对局域性质、几何、轨道形状比较可靠;对电荷转移激发能严重偏低 |
| ωB97X-D3 | 范围分离杂化 | 近程约 22%,远程 100% | 远距离电子相互作用正确渐近,适合电荷转移态 |

精确交换就是 Hartree–Fock 中的交换项,它在远距离上行为正确。电荷转移激发(电子从一个片段跑到另一个片段)对远程行为敏感,所以 PBE0 这类固定比例的泛函会把这类激发能低估,本项目里实测约低估 **2 eV**。所以必须用远程校正泛函再算一遍交叉验证。

### 8.3 基组和赛势

轨道 φᵢ 用一组预先定义的高斯函数(基组)线性组合来表示。**def2-SVP** 每个价层轨道用两个函数,再加极化函数,是可用的最小可靠基组。它有两个已知局限:没有弥散函数对阴离子外层电子有点过紧;激发态能量会偏高。更大的 def2-TZVP 会更准,但耗时明显更长(你选择了不跑)。

**赛势(ECP)**:Sn 有 50 个电子,内层 28 个几乎不参与化学反应,但要花大量基函数描述。ECP 用一个有效势把它们代替,同时把标量相对论效应带进来,计算更快、更准。

### 8.4 加速技巧:RIJCOSX

杂化泛函需要算大量四中心电子排斥积分,最慢。RIJCOSX 把计算分两份:库仑(J)部分用 RI 近似(用辅助基组 def2/J 展开密度),交换(K)部分用 COSX(格点数值积分和解析积分混合)。误差通常小于 1 kcal/mol,速度提升 5–10 倍。

### 8.5 色散校正 D3BJ

DFT 对范德华吸引描述不足。Grimme 的 D3 加一个经验项:

```latex
E_{\mathrm{disp}}=-\sum_{A<B}\left[ s_6\frac{C_6^{AB}}{r_{AB}^6 + f(R_0^{AB})^6} + s_8\frac{C_8^{AB}}{r_{AB}^8 + f(R_0^{AB})^8}\right]
```

其中 C₆、C₈ 是原子对的色散系数,f 是阻尼函数(BJ 阻尼),避免近距离发散。对本项目这种阳离子基团之间有 π 堆积、氢键的体系很有必要。ωB97X-D3 已经自带了这部分。

### 8.6 TD-DFT:怎么算激发态

TD-DFT(含时 DFT)用线性响应理论求分子对光电场的响应,求解 Casida 方程:

```latex
\begin{pmatrix} \mathbf A & \mathbf B \\ \mathbf B & \mathbf A \end{pmatrix}\begin{pmatrix}\mathbf X\\ \mathbf Y\end{pmatrix}=\omega\begin{pmatrix}\mathbf 1&0\\0&-\mathbf 1\end{pmatrix}\begin{pmatrix}\mathbf X\\ \mathbf Y\end{pmatrix}
```

本征值 ω 就是垂直激发能,X、Y 给出该激发态由哪些“占据轨道→空轨道”跃迁组成。输入中 `tda false` 表示保留 B 矩阵(完整 RPA),`tda true` 则令 B = 0(Tamm–Dancoff 近似)。

**垂直激发**指在基态几何上直接算激发能,不考虑激发后结构弛豫,所以对应的是**吸收谱**,不是发射谱。

### 8.7 振子强度和波长

```latex
\lambda\,(\mathrm{nm})=\frac{1239.84}{E\,(\mathrm{eV})},\qquad
f=\frac{2}{3}\,E\,|\langle 0|\hat{\mu}|n\rangle|^2\;\;(\text{a.u.})
```

- E 是激发能,转成波长直接用第一个公式。
- f 是**振子强度**,正比于跃迁偶极矩的平方。f 大说明吸收强(允许跃迁),f ≈ 0 说明几乎不吸收(禁阻或空间重叠很小)。一般 f > 0.1 算强吸收,低于 0.01 几乎看不到。

### 8.8 电荷转移(CT)与局域激发(LE)

| 类型 | 电子从哪到哪 | 本项目中的例子 | 典型特征 |
| --- | --- | --- | --- |
| LE(局域激发) | 同一个片段内 | 阳离子 π→π\* | f 大,对泛函不敏感 |
| CT(电荷转移) | 不同片段之间 | SnCl6 → 阳离子 | f 很小、能量对泛函极敏感 |

判断一个激发态是 CT 还是 LE,看的是电子跃迁发生前后哪个片段的电子成分变了,这就是下一节 Löwdin 分析的目的。

### 8.9 Löwdin 轨道分析

分子轨道 φᵢ 是原子轨道的线性组合 φᵢ = Σμ Cμi χμ。Löwdin 方法先用 S^(1/2) 把基组正交化,再把每个原子上的系数平方相加,得到每个原子对轨道 i 的百分比贡献:

```latex
q_{A,i}=\sum_{\mu\in A}\left|\left(\mathbf S^{1/2}\mathbf C\right)_{\mu i}\right|^2
```

把属于同一片段(SnCl6、水、阳离子)的原子贡献加起来,就能说“这个轨道 61% 在 SnCl6 上”。对比 Mulliken,Löwdin 对基组依赖小、不会出现负的占据数,所以更适合这类分析。

### 8.10 把激发态归属到片段

每个激发态在输出里写成很多组“轨道 a → 轨道 b,权重 w”。我的分析脚本用这些权重对各轨道的片段成分做**加权平均**:

```latex
P^{\mathrm{donor}}_F=\frac{\sum_k w_k\,q_{F,a_k}}{\sum_k w_k},\qquad
P^{\mathrm{acceptor}}_F=\frac{\sum_k w_k\,q_{F,b_k}}{\sum_k w_k}
```

得到的就是“给出电子的片段”和“接收电子的片段”的百分比分布。这是一个近似的快速办法,最严格的办法是 NTO(自然跃迁轨道)或 Multiwfn 的空穴–电子分析,见第十一节的局限说明。

| S14 | 5.596 | 221.6 | 0.0031 | SnCl6 85% + H2O 9% → 阳离子 3 号 97% | CT |
| S15 | 5.665 | 218.8 | 0.0133 | SnCl6 94% → SnCl6 92% | SnCl6 内部 |

注:“阳离子 3/4 号”是两个独立的 2-苯基咪唑鎓阳离子(编号按原子顺序)。S9 的去向中阳离子成分约 20–30%,具体比例我没有完全确认,所以这里只写了可以确认的部分。

### 9.5 把两组结果放在一起看

| 指标 | PBE0 | ωB97X-D3 | 含义 |
| --- | --- | --- | --- |
| 最低激发态 | 3.275 eV(379 nm) | 5.002 eV(248 nm) | 相差约 1.7 eV |
| 最低激发态类型 | CT,f ≈ 0.004 | LE π→π\*,f = 0.22 | 性质也不同 |
| 最强跃迁 | 没有 f > 0.005 | S3/S4,f ≈ 0.37 | 强吸收由阳离子贡献 |
| CT 态位置 | 3.3–3.9 eV | ≥ 5.26 eV(多数 5.4 eV 以上) | CT 态往高能移了约 2 eV |

这张表是结论的核心:**PBE0 的 3.3–3.9 eV "低能跃迁"是泛函人造的结果,真实的 CT 态在 5.4 eV 以上**。真正的吸收起始由阳离子的 π→π\* 决定,在 250 nm 附近。

### 9.6 这些结果能帮你回答什么研究问题

1. **吸收边在哪里?** 在单分子簇模型里约 250 nm。如果实验吸收边比这长很多,说明晶体里的堆积、极化、缺陷等因素起了作用,这些这个模型没有包含。
2. **有没有 Sn²⁺ 类型的 5s→5p 发光?** 没有。Sn⁴⁺ 的 d¹⁰ 层已满,没有 5s 孤对电子,这个化合物的光学性质由有机阳离子和 Cl→阳离子 转移决定,不是金属中心。
3. **该不该期待有亮的电荷转移发光?** 相当一部分 SnCl6→阳离子 的 f ≈ 0,说明这些态很“暗”,不太可能贡献强发光。
4. **阳离子基团是吸光主体**:S3、S4、S7 三个强跃迁都是阳离子内部的 π→π\*。要调节吸收,改阳离子(换取代基、延长共轭)比改阴离子有效。

### 10.1 build.py:从 CIF 到团簇

这段脚本的逻辑分四步:解析原子表、转笛卡尔坐标、按键分块、把每一块移到 SnCl6 附近。核心部分如下(省略了输入输出细节):

```python
import numpy as np, re, itertools

# 1) 晶胞矩阵(三斜晶系)
a, b, c = 7.6939, 10.9454, 15.4984
al, be, ga = np.radians([86.698, 80.216, 82.508])
v = np.sqrt(1 - np.cos(al)**2 - np.cos(be)**2 - np.cos(ga)**2
            + 2*np.cos(al)*np.cos(be)*np.cos(ga))
M = np.array([
    [a,               0,                                    0],
    [b*np.cos(ga),    b*np.sin(ga),                         0],
    [c*np.cos(be),    c*(np.cos(al)-np.cos(be)*np.cos(ga))/np.sin(ga),
                                                            c*v/np.sin(ga)],
])

# 2) 分数坐标 -> 笛卡尔坐标
frac = np.array(frac_list)          # (53, 3)
cart = frac @ M

# 3) 按共价半径×1.25 判断成键,BFS 找连通分量
rad = {'H':0.31,'C':0.76,'N':0.71,'O':0.66,'Cl':1.02,'Sn':1.39}
def bonded(i, j, d):
    return d < 1.25 * (rad[el[i]] + rad[el[j]])

# 4) 对每个片段尝试 ±1 倍晶胞平移,选离 SnCl6 质心最近的
shifts = list(itertools.product([-1, 0, 1], repeat=3))
best = min(shifts, key=lambda s: dist(frag_centroid + np.array(s) @ M, sn_centroid))
```

最后写出 `cluster.xyz`,并检查 Sn–Cl 键长是否正常(约 2.4 Å)。

### 10.2 run2.sh:让脚本自动生成优化输入

手工写 53 行约束容易出错,所以用 awk 自动生成。这段的思路:扫描坐标文件,把所有非氢原子的序号写入 cons.txt。

```bash
# 生成约束列表:原子序号从 0 开始,跳过 H
awk '$1 != "H" {printf "  {C %d C}\n", NR-1}' coords.txt > cons.txt

# 拼接输入文件
cat > phim_opt.inp <<EOF
! PBE0 D3BJ def2-SVP def2/J RIJCOSX TightSCF Opt
%pal nprocs 6 end
%maxcore 6000
%geom
 MaxIter 150
 Constraints
$(cat cons.txt)
 end
end
* xyz 0 1
$(cat coords.txt)
*
EOF

/opt/orca/orca phim_opt.inp > phim_opt.out
```

`NR-1` 是 awk 的行号减 1,正好对应 ORCA 从 0 开始的原子编号。优化结束后再生成 TD 输入(用 `xyzfile` 读取 phim\_opt.xyz)并继续跑。

### 10.3 analyze.py:片段划分、轨道成分、激发态归属

这段脚本是整个分析的关键。它分三步:

1. \*\*用距离判断片段。\*\*先读 phim\_opt.xyz,按距离建立连接关系:Sn–Cl < 3.0 Å,重原子对 < 1.9 Å,H–X < 1.3 Å。连通分量共 5 个:SnCl6(7 个原子)、H2O1(3)、H2O2(3)、Cat3(20)、Cat4(20)。
2. \*\*读轨道成分并按片段求和。\*\*在输出里找到最后一个“LOEWDIN REDUCED ORBITAL POPULATIONS PER MO”块,把每个轨道的各原子百分比加到对应片段上。
3. \*\*解析激发态并加权。\*\*读每个 STATE 块里的跃迁列表 `a -> b : weight`,用权重对给体/受体片段占比做加权平均(即 8.10 的公式)。

关键代码结构:

```python
# 片段划分(仅示意核心逻辑)
cut = {('Sn','Cl'): 3.0}
def linked(i, j, d):
    ei, ej = el[i], el[j]
    if 'Sn' in (ei, ej):
        return d < 3.0 and {ei, ej} == {'Sn', 'Cl'}
    if 'H' in (ei, ej):
        return d < 1.3
    return d < 1.9

# 片段累加
def frag_pop(mo_row):
    out = {f: 0.0 for f in fragments}
    for atom_idx, pct in mo_row.items():
        out[frag_of[atom_idx]] += pct
    return out

# 激发态:权重加权平均
def weighted(transitions, side):
    tot = sum(w for _, _, w in transitions)
    res = {f: 0.0 for f in fragments}
    for a, b, w in transitions:
        mo = a if side == 'donor' else b
        for f, p in frag_pop(pop[mo]).items():
            res[f] += w * p
    return {f: v / tot for f, v in res.items()}
```

**踩过的一个坑**:ORCA 输出里有两张靠近的吸收谱表,一张基于跃迁电偶极矩(带 f 列),另一张基于速度表象(带 D2 列)。最初我把后一张的 D2 当成了 f,后来在读到第一张表的结尾(空行)就停止,才清除这个错误。所以前面把“S1 的 f”写错的那次,已经在文中和对话里更正,文中的结果已经是正确值。

用法:

```bash
python3 analyze.py pop.out phim_td.out      # PBE0
python3 analyze.py wb_td.out wb_td.out     # ωB97X-D3(同一文件既有轨道分布也有激发态)
```

### 10.4 render.py:把 cube 变成轨道图

cube 文件是一个三维网格上的数值,需要用“等值面提取”算法把波函数为 +0.03 和 −0.03 的面画出来。脚本用 scikit-image 的 marching cubes,再用 matplotlib 绘制。核心代码:

```python
import numpy as np
from skimage.measure import marching_cubes
import matplotlib.pyplot as plt
from mpl_toolkits.mplot3d.art3d import Poly3DCollection

def read_cube(path):
    lines = open(path).read().split('\n')
    natoms = int(lines[2].split()[0])
    skip = 1 if natoms < 0 else 0      # ORCA 的 cube 把 natoms 写成负数,多一行
    natoms = abs(natoms)
    nx, ny, nz = [int(lines[3 + k].split()[0]) for k in range(3)]
    data_start = 6 + natoms + skip
    vals = np.array(' '.join(lines[data_start:]).split(), float)
    return vals.reshape(nx, ny, nz)

def draw(ax, vol, level, color):
    verts, faces, _, _ = marching_cubes(vol, level=level)
    ax.add_collection3d(Poly3DCollection(verts[faces], facecolor=color, alpha=0.6))

vol = read_cube('mo148.cube')
draw(ax, vol,  0.03, 'red')    # 波函数为正
# 负相位用 -vol 求等值面
draw(ax, -vol, 0.03, 'blue')
```

**踩过的第二个坑**:ORCA 的 cube 文件头里原子数是负数(标记“有轨道编号这一行”),读取时要多跳一行。第一版校验忽略了这点,算出的模和归一化都不对;修正后轨道的平方积分 ≈ 0.997–0.999(理论上应为 1),说明网格足够细、数据正确。

## 十一、局限、可靠性与更正说明

这一节最重要:告诉你哪些结论可以直接用,哪些只能当定性参考。

### 11.1 模型局限

| 局限 | 影响 | 怎么改进 |
| --- | --- | --- |
| 真空中的单个团簇,没有周期性和晶体场 | 没有 Madelung 电势,空轨道/占据轨道的相对位置和真实晶体不同;带电片段的静电环境不完整 | 加嵌入电荷、用 CPCM 模拟介电环境,或改用周期性 DFT(VASP、CP2K) |
| 只有 def2-SVP | 激发能绝对值可能偏高数十到上百 meV;对阴离子缺弥散 | 用 def2-TZVP 或加 diffuse(你选择了跳过) |
| 重原子冻结在 X 射线位置 | 没有完全弛豫,重原子位置相对真实最优结构可能有小幅偏差 | 全优化(耗时会明显增加) |
| 只算垂直激发 | 得到的是吸收,不是发射;没有激发态弛豫 | 优化 S1 态几何,再算发射 |
| 15 个态不足以覆盖 CT 带 | 高能处还有更多态 | 增加 nroots |
| 片段归属用的是轨道占比加权 | 是一个近似,当一个态由多个跃迁混合时容易丢细节 | 用 NTO 或 Multiwfn 空穴–电子分析 |
| 氢键和氢位置来自模型修正 | 氢位置已经优化,但其他原子位置仍是实验值 | 与全优化结果对照 |

### 11.2 最关键的警示:不要把计算值当成实验值

上述所有能量都是**单个分子团簇的垂直激发能**。要和实验的晶体吸收/发射光谱对比,至少要考虑三件事:

1. 晶体里的电子能带这一级的展宽(分子间互作用会让吸收边红移)。
2. 激发态弛豫和激子效应。
3. 缺陷、杂质、温度。

所以应该把这些结果理解成\*\*“这个化合物的电子态结构是怎样分层的”\*\*,而不是“它的实验吸收边就是 248 nm”。

### 11.3 可以相对放心的结论

- 前线轨道的空间分布:最高占据轨道在 SnCl6 的 Cl 上,最低空轨道在阳离子的苯基咪唑环上。两个泛函都得到这一点,很稳健。
- 阳离子内部 π→π\* 是主要吸收贡献者(S3、S4、S7 的 f 大)。
- Sn⁴⁺ 不产生 5s→5p 类型的跨迁,项目化合物不属于 Sn²⁺ 型的发光体系。
- 氢键位置的修正是必要的(222 kcal/mol 的异常能量已说明)。

### 11.4 要谨慎对待的结论

- 所有“绝对激发能”的具体数字(例如 5.002 eV)。
- CT 态的精确位置和排序(尤其 S5–S15 的排序会随泛函、基组改变)。
- 水分子的轨道贡献百分比(PBE0 下有假离域化)。
- 所有 Löwdin 百分比是近似值,不同分析方法可相差 5–15 个百分点。
